Build notes (not part of the screen)

Why
The language toggle only shows when an alert card is on screen (Staff.jsx:104–114). A Kannada or Hindi speaker first meets ShieldMate in English, in the middle of an attack. The sound unlock is a small topbar button that's easy to miss, and nothing tells staff that alerts only arrive while the page is on screen.
When it shows
On the first visit to /staff/:id on a phone (seenOnce("welcome-<staffId>")). It can be skipped, and reopened from the Help tab.
Data
Client only: session.setLang, fx.unlockAudio() and alertFx(), and the staff name from GET /clinic. No API change.
Also
Show the language toggle on Today too, not only on a card.
Accuracy
usePoll pauses while the tab is hidden, and there is no push yet (OwnerNotify.jsx: “real push notifications come after the demo”). The copy must not promise alerts on a locked phone.
Translations
Only the language names appear in Kannada and Hindi here. The new sentences need the fluent checker before they're translated (T2.05).
