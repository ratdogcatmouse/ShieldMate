Build notes (not part of the screen)

Why
Once an incident closes, its story is hard to find: Right now keeps only the 3 newest in “Closed today” (OwnerNow.jsx:430), and “What happened” shows the newest 7 events (OwnerNow.jsx:471). Nothing lists every incident.
Data
What Right now already polls: GET /alerts?role=owner&include_closed=true, GET /actions, GET /notifications?role=owner, run through derive.activity() unchanged. The practice row is GET /status → simulation.
Small code changes
  • Give each activity() event a kind (alert, step, block, it, note) and its alert_id, so the filters and Incident detail can use it. Add tests in derive.test.js.
  • Rows link to /owner/incident/:id; so do the headlines on Right now and in “Closed today”.
States
Empty: “Nothing has happened since the last reset.” A Reset restarts alert ids, so the list only covers time since the last reset. The event log keeps older history but has no read route, and adding one is out of scope.
Phone layout
The owner tab bar has four slots. History, Computers and Setup go in a “More” sheet that replaces “Switch” (it moves into the sheet too).
